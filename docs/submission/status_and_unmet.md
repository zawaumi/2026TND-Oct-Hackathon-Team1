## 3. リリース判定（docs/06 の E、必須ゲート）

| ゲート | 判定 | 理由 |
|---|---|---|
| P0 機能の E2E デモの再現 | 確認済み | 本番で、ログイン〜教える〜出題〜習得〜レポートまで通した |
| 他人データの拒否 | 確認済み（主要 API） | SEC-T02 の各テスト。**全 API を網羅した攻撃耐性の試験は、未実施** |
| 不正な MASTERED 遷移なし | 確認済み | AI の出力では習得済みにならない。習得済みへ進むのは、検証済みの出題による習得判定だけ（`AT03`・`AT04`） |
| API キーの未露出 | 確認済み | DeepSeek のキーは Secret Manager だけに置き、画面のビルドには含めない（`check-no-mock` とビルドの検査）。Firebase の Web 用 API キーは、公開前提の識別子としてコードにある |
| データ削除の手順あり | **未達** | 退会の API も、削除の手順書も、まだない |

**判定（案）**：**一般向けの公開は、まだできない**（必須ゲート「データ削除の手順あり」が未達）。審査では、動作 URL で本物の動きを見せる。最終の判定は、チームで決める。
