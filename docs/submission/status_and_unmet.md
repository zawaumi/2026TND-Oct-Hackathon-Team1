# 実装状況と未達の記録（最終提出時点）

**日付** 2026-11-14（最終提出日）／**対象** `main`（7bda887）

この文書は、「何が動き、何が動かないか」を、**確認した事実だけで**書いた記録である。`docs/06` の方針（未実装の項目を「実装済み」と説明しない）に従う。試験の ID は `docs/06`、要求の ID は `docs/09` に合わせてある。

## 0. 要約

- **動くもの**：ログインの本人確認、初回登録、教材選択、「教える」会話（外部の AI はモック）、学習レポート、知識マップ。API は本物のコードで、自動テストがある（API 142 件。受入試験を足して 150 件）。
- **動かないもの**：**出題 → 検証 → 習得判定**（API が未実装）、退会・データ削除、知識リセット、設定の画面、動作 URL（未配備）。
- **画面だけ動くもの**：「問題を出す」〜習得の演出は、**モックの API で画面の動きを確認した**だけで、実際の習得判定ではない。
- 本物の API では、知識マップの**前提の矢印が出ない**（前提関係のモデルが、まだない）。
- 外部 AI（DeepSeek・Jev）と Firebase は、**実際の接続を確認していない**。

## 3. リリース判定（docs/06 の E、必須ゲート）

| ゲート | 判定 | 理由 |
|---|---|---|
| P0 機能の E2E デモの再現 | **未達** | 本物の API では、出題〜習得が通らない。画面＋モックでは再現できる |
| 他人データの拒否 | 確認済み（主要 API） | SEC-T02 の各テスト。**全 API を網羅した攻撃耐性の試験は、未実施** |
| 不正な MASTERED 遷移なし | 確認済み | AI の出力では習得済みにならない。ただし、習得済みへ進む正規の経路は、まだない |
| API キーの未露出 | 一部 | コード・手順書・ビルドの検査で、キーを含めない作りを確認。**本番の配備が未実施で、実環境では未確認**（Firebase の Web 用 API キーは、公開前提の識別子としてコードにある） |
| データ削除の手順あり | **未達** | 退会の API も、削除の手順書も、まだない |

**判定（案）**：**一般向けの公開は、できない**（必須ゲートのうち 2 つが未達、1 つが一部）。審査では、**デモ版（画面＋モック）である旨を明示**して見せ、本物の API の範囲（教える会話・レポート・安全性の試験）と分けて説明する。最終の判定は、チームで決める。
