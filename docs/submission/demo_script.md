# デモの台本と通し練習の手順

## 0. 最初に言うこと

> 「これから、配備した本番（https://tnd2026-oct-hackathon.web.app ）で見せます。ぴあ友の応答は本物の AI（DeepSeek）、習得済みにするかどうかは、サーバーの判定です。」

本番が使えず、ローカルのデモ版（モック）に切り替えたときは、**「ここからはデモ版（疑似データ）です」と口頭で言う**（画面に「デモ」の表示は出ない）。

## 1. 準備（発表の前に）

- [ ] 端末：（何を使うか）／ブラウザ：Google Chrome。画面の拡大率 100％。通知を切る。別のタブを閉じる
- [ ] **発表用の Google アカウントを決める。** ぴあ友の知識は、アカウントごとに残り、リセットの機能はまだない。**練習で使ったアカウントでは、概念がすでに習得済みになっていて、同じ流れを見せられない。** 練習と本番で、別のアカウントを使う
- [ ] 発表の 10 分前に、待ち時間をなくす：`gcloud run services update piatomo-api --region asia-northeast1 --min-instances 1`（終わったら `--min-instances 0` に戻す）
- [ ] 本番の URL を開き、発表用のアカウントでログインし、初回設定まで済ませておく
- [ ] **予備**：ローカルのデモ版（`cd apps/web && npm run dev`、http://localhost:3000）が動くこと。事前に撮った画面録画と、スクリーンショット（[screens/](screens/README.md)）をすぐ開ける場所に置く
- [ ] 会場のネットが使えないときのために、スマホのテザリングを用意する

### 説明の例（コピーして使う）

1. 等式の両辺に同じ数をたしても等しいのは、つり合いがくずれないからだよ。たとえば x+3=7 なら両辺から3をひく。
2. 両辺を同じ数でわっても等しいままだよ。でも0でわるのはだめ。たとえば 2x=6 は両辺を2でわると x=3 になる。
3. （「移項」の授業で）移項するときは符号が変わるよ。それは両辺から同じ数をひくのと同じだから。たとえば x+2=5 なら x=5-2。

## 3. 予備の手段（動かないとき）

- **A. 本番の応答が遅い・エラーが出る**：一度だけ「もう一度」を押す。だめなら、ローカルのデモ版に切り替え、「ここからはデモ版（疑似データ）です」と言う。
- **B. 端末やネットが動かない**：事前に撮った画面録画を流す。なければ、[screens/](screens/README.md) のスクリーンショットを、順に見せる。
- **C. 時間が足りない**：★の手順だけにする。

## 5. 想定される質問と答え

1. **AI が勝手に習得済みにしないのは、どう保証する？**
   習得済みにできるのは、サーバー（DRF）の判定だけです。AI の出力は検証して、不正なら棄却します。AI が「分かった」と何度言っても、習得済みにならないことを、自動テストで確認しました。習得済みになるのは、検証済みの出題で習得条件を満たしたときだけです。
2. **習得は、どう判定する設計？**
   ぴあ友は、説明を受けた概念の技能だけで、1 行ずつ解きます。サーバーは、解き方とは別の方法（各行の解・代入）で検証し、正しければ根拠にします。必要な正答数と、異なる形の数を満たしたら、習得済みです（基礎は 1 問、標準は違う形の 2 問）。同じ形のくり返しは、数えません。式は `eval` を使わずに、一次方程式の文法だけで読みます。
3. **個人情報は、どう扱う？**
   会話の本文は DB に残さず（DB 全体を検索して確認）、外部の AI へは、識別子を送りません（自動テスト）。**退会・データ削除は、未実装**です。
4. **未成年の同意は？**
   同意の文面は**仮**で、法務の確認は、まだです。今回は、ハッカソン用の限定 MVP で、一般公開はしません。
5. **DeepSeek と Jev の比較実験は？**
   45 件の架空の会話と、2 名が独立に採点するための道具を準備しました。**採点は、未実施**です。優位性は前提にせず、45 件と少ないので、統計的な証明もできないと考えています。会話は AI が書いたので、AI の採点に有利・不利に働く可能性も、限界として記録しました。
6. **教育的な根拠は？**
   学習指導要領（中学校 数学 第 1 学年 A 数と式 (3)）と、国立教育政策研究所の資料に基づく教材で、数学の内容と出典は、人が確認しました（頁番号の一部は未確認）。
7. **配点（40・30・30）の根拠は？**
   仮の値です。比較実験の結果で、見直す予定です。
8. **なぜ、中 1 の一次方程式だけ？**
   数式を安全に検証できる範囲に限るためです（文章題は、公開しません）。自由学習・探究学習は、今後の拡張です。
9. **どこで動いている？**
   Firebase Hosting（画面）・Cloud Run（API）・Cloud SQL（DB）に配備しました。秘密の値は Secret Manager にだけ置いています。手順は `docs/deploy.md` にまとめました。
10. **アクセシビリティは？**
    幅 1280・390、キーボード、読み上げ用の名前、動きを減らす設定を確認しました。実機・スクリーンリーダー・他のブラウザは未確認で、青地の白い文字のコントラストは、未対応です。
11. **開発では、生成 AI を使ったか？**
    使いました（Claude・GitHub Copilot・画像は ChatGPT）。内容は、人が確認しています（[status_and_unmet.md](status_and_unmet.md) の 9 節）。
