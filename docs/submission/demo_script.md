### 説明の例（コピーして使う）

1. 等式の両辺に同じ数をたしても等しいのは、つり合いがくずれないからだよ。たとえば x+3=7 なら両辺から3をひく。
2. 0でわれないのは、答えが決まらないからだよ。たとえば 2x=6 は両辺を2でわる。
3. 移項するときは符号が変わるよ。それは両辺から同じ数をひくのと同じだから。たとえば x+2=5 なら x=5-2。

## 3. 予備の手段（動かないとき）

- **A. 開発サーバーが動かない／画面が崩れた**：ブラウザを再読み込み（モックが初期状態に戻る）。それでも駄目なら、`npm run dev` を再起動。
- **B. 端末が動かない**：事前に撮った画面録画を流す。なければ、[screens/](screens/README.md) のスクリーンショットを、順に見せる。
- **C. 時間が足りない**：★の手順だけにする。

どの場合も、**「デモ版」である旨を、言い換えずに言う。**

## 5. 想定される質問と答え

1. **AI が勝手に習得済みにしないのは、どう保証する？**
   習得済みにできるのは、DRF の判定だけで、AI の出力は、検証して、不正なら棄却します。AI が「分かった」と言っても、習得済みにならないことを、自動テストで確認しました。**ただし、検証済みの出題による習得判定そのものは、まだ未実装です。**
2. **習得は、どう判定する設計？**
   検証済みの出題で、必要な正答数と、異なる形式の数を満たしたら、習得済みにします（設計）。同じ形のくり返しは、数えません。**実装は未で、画面はデモ版で見せています。**
3. **個人情報は、どう扱う？**
   会話の本文は DB に残さず（DB 全体を検索して確認）、外部の AI へは、識別子を送りません（自動テスト）。**退会・データ削除は、未実装**です。
4. **未成年の同意は？**
   同意の文面は**仮**で、法務の確認は、まだです。今回は、ハッカソン用の限定 MVP で、一般公開はしません。
5. **DeepSeek と Jev の比較実験は？**
   45 件の架空の会話と、2 名が独立に採点するための道具を準備しました。**採点は、未実施**です。優位性は前提にせず、45 件と少ないので、統計的な証明もできないと考えています。会話は AI が書いたので、AI の採点に有利・不利に働く可能性も、限界として記録しました。
6. **教育的な根拠は？**
   学習指導要領（中学校 数学 第 1 学年 A 数と式 (3)）と、国立教育政策研究所の資料に基づく教材で、数学の内容と出典は、人が確認しました（頁番号の一部は未確認）。
7. **配点（40・30・30）の根拠は？**
   仮の値です。比較実験の結果で、見直す予定です。
8. **なぜ、中 1 の一次方程式だけ？**
   数式を安全に検証できる範囲に限るためです（文章題は、公開しません）。自由学習・探究学習は、今後の拡張です。
9. **動作 URL がないのは、なぜ？**
   配備には、クラウドの権限が必要で、設定と手順書までを用意しました。実際の配備は、未実施です。
10. **アクセシビリティは？**
