# MVPの受入試験の記録（教材選択 → 説明 → 出題 → 検証 → 習得 → レポート）

MVPの一連の流れを通して、受入テスト（docs/06）の AT-03・04・05・10・12 を確かめた記録。
**結論：通しの試験を行えた。** AT-03・04・05・10・12 は、API の自動テストで合格した（公開教材のデータを入れ、外部の AI だけをモックにして、教える → 問題を出す → 習得 を API だけで通す）。さらに、配備した本番（https://tnd2026-oct-hackathon.web.app ）で、本物の Google ログインと DeepSeek を使って、画面から最後まで通した（7 節）。

### AT-03（API）
- 試験：`apps/api/learning/test_acceptance.py` の `AT03_AiSaysUnderstood`。
- 期待：AI が「すごくよく分かりました！」と、成功の表情（`mastery_success`）つきで、6 回答えても、習得済みへの変化は 1 つもなく、DB に習得済み・習得した日時が入らず、画面に返る表情に `mastery_success` が出ない。出力の検証に通らない応答（`master_all`）は、定型の応答になり、知識は変わらない。
- 実測：期待どおり。

### AT-10（API）
- 試験：同 `AT10_RestartRestoresKnowledgeOnly`。
- 期待：説明を送って、授業を終え、新しいクライアント（同じ本人。ブラウザの会話がない状態）で取ると、知識（「移項」が説明済み）は取れる。授業の取得に、会話の本文は含まれない。会話の本文が、DB のどのテーブルにも残っていない。
- 実測：期待どおり。DB 全体の検索が、本当に文字を見つけられることも、わざと入れた文字で確認した（検索の道具が壊れていない）。

## 2. 手順ごとの確認（画面・モック）

| 手順 | 期待 | 実測 |
|---|---|---|
| 教材選択 | 小単元「方程式の解法」を選べる | 期待どおり |
| セッション作成 | 授業を始めると、学習ルームへ進む | 期待どおり |
| 説明 → 質問 | 説明を送ると、ぴあ友が質問を返す | 期待どおり（理由をたずねる質問） |

| 同じ形 `x+5=9` | 「前と同じ形」で、回数は増えない | 期待どおり（あと 1 問のまま） |
