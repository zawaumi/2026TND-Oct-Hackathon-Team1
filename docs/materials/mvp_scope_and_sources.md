## 1. 範囲の決定

MVPで扱うのは、**中学校・数学・第1学年の「Ａ数と式（3）一元一次方程式」だけ**。理由は、式変形を一次方程式の決まった形に限れば、サーバーが正誤と各ステップを自動で検証できるため（`docs/00_master_spec.md` の 6）。全学年・全教科を扱わない方針（同 1.2・「約束しないこと」）とも合う。

### 1.1 中1数学の「内容のまとまり」の候補

国研資料 p.27 の、第1学年の内容のまとまりの一覧による。

| 内容のまとまり（公式） | 採否 | 理由 |
|---|---|---|
| Ａ数と式（1）正の数と負の数 | 対象外 | 期限内に1つの内容のまとまりに絞る。文章で説明する部分が多く、自動で検証しにくい |
| Ａ数と式（2）文字を用いた式 | 対象外 | 同上。ただし、一元一次方程式の前提として、一次式の計算ができることを仮定する |
| **Ａ数と式（3）一元一次方程式** | **採用** | 検証できる式変形に絞れる。ADR-028 の3小単元がここに入る |
| Ｂ図形（1）平面図形／（2）空間図形 | 対象外 | 作図・証明など、数式の検証にならない |
| Ｃ関数（1）比例，反比例 | 対象外 | 期限内に、グラフの扱いまで作れない |
| Ｄデータの活用（1）（2） | 対象外 | 検証の方法が別に要る |

### 1.2 「一元一次方程式」の中の小単元（アプリ独自）

| 小単元（アプリ独自の名前） | 採否 | 公開 | 理由・備考 |
|---|---|---|---|
| 等式の性質 | **採用** | 公開（MVP） | 国研資料 p.52 の事例で、第3時に扱われる内容。たす・ひく・かける・わるを、両辺に同じように使えることを扱う |
| 方程式の解法 | **採用** | 公開（MVP） | 解の意味と、等式の性質を使って解くこと。整数・有理数の係数、文字は x 1つ |
| 移項 | **採用** | 公開（MVP） | 国研資料 p.52・p.57 の事例で、等式の性質を基に説明する内容。たす・ひくだけで解ける形に絞る |
| 方程式の利用（文章題） | **保留（非公開）** | 公開しない（ADR-028） | 文章から式を立てる部分を自動で採点しにくい。概念は知識マップに未習として出し、おすすめや次の学習の候補には出さない |
| 比例式 | 対象外 | — | 国研資料の事例（p.51 の評価規準）に出てくるが、MVPの式の文法の外 |

## 2. 公式の分類と、アプリ独自の名前

| 階層 | 名前 | 公式／独自 |
|---|---|---|
| 校種・教科・学年 | 中学校・数学・第1学年 | 公式 |
| 領域 | Ａ数と式 | 公式 |
| 内容のまとまり | （3）一元一次方程式 | 公式 |
| 単元（アプリ） | 一元一次方程式 | 公式の内容のまとまりと同じ名前を、アプリの単元として使う |
| 小単元（アプリ） | 等式の性質／方程式の解法／移項／方程式の利用（文章題） | **アプリ独自**。名前も分け方も、公式の分類ではない |
| 概念（アプリ） | 等式の両辺に同じ数をたす・ひく、ほか4つ | **アプリ独自** |

- 国研資料の事例2は、学習評価の「事例」の一つで、公式の単元分類ではない。その小単元（「一元一次方程式とその解」「解き方」「利用」）とは別の分け方にしている。
- 教育データ標準の「学習指導要領コード」は未確認。`official_code` は空にしてある。コードを調べて入れるのは、別の確認作業にする。

## 4. 実現可能性（量）

- 公開する小単元は3つ（ADR-028）。概念は4つ（公開）＋1つ（非公開）。
- 例題は12問（自動採点できるもの）＋参考1問。全ステップを検算コードで確認済み。
- 期限：機能凍結 11/13、最終提出 11/14（`docs/00_master_spec.md` の 13）。データは作成済みで、追加の作業は、レビューと、前提関係・習得条件のモデルの追加の待ち。
- 数学の範囲：一次方程式（整数・有理数の係数、文字は x 1つ）。かっこ・小数・分数の係数、文章題は MVP に入れない。

## 5. 未検証・要確認

1. 学習指導要領の本文での、Ａ(3) の項目と頁の照合（3節）。
2. 解説 数学編での、Ａ(3) の定義・用語・内容の取扱いの確認。
3. 教育データ標準の学習指導要領コード。
4. 小単元の分け方が、教科書の一般的な順序と大きくずれていないか（国研資料の事例の順序は、等式の性質 → 移項 → 解き方）。アプリの順序は ADR-028 の「等式の性質・方程式の解法・移項」。
5. 国研・文部科学省の資料の引用・利用条件（法務の確認に含めるか）。
6. 「文字を用いた式」（Ａ(2)）を前提として仮定することの妥当性。
