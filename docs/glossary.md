# 用語集

**版** 1.1 / **改訂日** 2026-11-08

仕様書・画面・コード・発表資料では、この表の言葉を使う。新しい用語を足すときは、先にこの表へ追加する。

## 1. 名前

| 用語 | 意味 | 使わない表記 | コード・API |
|---|---|---|---|
| ぴあとも | このアプリの名前。英字表記は Piatomo | PiaTomo、PIATOMO | `piatomo` |
| ぴあ友 | ユーザーが勉強を教える、同年代のAI生徒 | AI生徒、生徒役AI、ピア | `Peer` |
| ユーザー | アプリを使う中学生・高校生。ぴあ友に教える側。画面では「あなた」「先生」と呼んでもよい | 学習者、教師本人 | `User` |

## 2. 学習と教材

| 用語 | 意味 | 使わない表記 | コード・API |
|---|---|---|---|
| 校種 | 中学校か高校か | 学校区分 | `school_level`（`middle`／`high`） |
| 教科・科目 | 数学、数学Ⅰ など。高校は科目を基準にする | ― | `subject` |
| 単元 | 学習指導要領の内容を、アプリで扱いやすくまとめた単位（例：一次方程式） | ― | `Lesson`（親） |
| 小単元 | 単元をさらに分けた、授業で選ぶ最小の単位（例：移項）。名前と分け方はアプリ独自 | 教材（総称として使う場合を除く） | `Lesson`（末端） |
| 概念 | ぴあ友が身につける知識・技能の単位。教科をまたいで共通 | スキル（技能の意味以外で） | `Concept` |
| 前提 | ある概念を学ぶ前に必要な概念 | ― | `ConceptPrerequisite`、`prerequisite` |
| 技能 | 数学で使える式変形の操作（例：両辺に同じ数をたす） | ― | `add_both_sides` などのルール名 |
| 学習モード | 単元学習・自由学習・探究学習の3つ | 単元選択モード、自由テーマモード、探究モード | `preset`・`free`・`inquiry` |
| 授業 | 小単元を選んでから終えるまでの1回の学習 | 講義（画面の文言を除く） | `LearningSession` |
| ターン | 授業の中の、ユーザーの1回の送信とぴあ友の1回の応答 | ― | `LearningTurn` |
| 問題を出す | ユーザーが問題を作り、ぴあ友に解かせること | 例題を出す（同じ意味で使ってよい） | `Exercise` |

## 3. ぴあ友の習得

| 用語 | 意味 | コード・API |
|---|---|---|
| 未習 | まだ教わっていない | `UNKNOWN` |
| 説明済み | 説明を受けたが、まだ問題で確かめていない | `INTRODUCED` |
| 練習中 | 説明された技能を、問題で使える段階 | `PRACTICING` |
| 習得済み | 検証済みの正答で習得条件を満たした | `MASTERED` |
| 習得条件 | 習得済みになるために必要な正答の数と、問題の形式の数 | `MasteryPolicy` |

画面では、この4つの言葉をアイコンと一緒に表示する。「覚えたこと」「わかった」など、別の言い方で状態を表さない。

## 4. 評価

| 用語 | 意味 | 使わない表記 | コード・API |
|---|---|---|---|
| 説明力スコア | ユーザーの説明を3観点で評価した、ぴあとも独自の点数。初出では「ぴあとも独自の説明力スコア」と書く | 学習支援スコア、カラオケ風スコア | `score`、`total_score` |
| 正確さ | 説明と、ぴあ友の質問への答えに誤りがないか（配点40、仮） | ― | `accuracy` |
| 論理性 | 手順や理由の筋道が通っているか。質問に根拠を示して答えられたか（配点30、仮） | ― | `logic` |
| 分かりやすさ | ぴあ友がつまずいたところを、言い換えや例で補えたか（配点30、仮） | 明確さ | `clarity` |
| 評価保留 | 根拠が足りないため、その観点を点数にしないこと | 未評価 | `UNRATED` |

旧仕様（v1.0）にあった「質問への対応」「振り返り」「網羅性」は、独立した観点としては使わない。ぴあ友の質問への対応は、3観点それぞれの中で評価する。

## 5. システム

| 用語 | 意味 | コード・API |
|---|---|---|
| Jev | ユーザーの説明を評価する外部AI（提供元は TypeSafe AI）。点数の候補を返すだけで、決定はしない | `integrations/jev` |
| DeepSeek | ぴあ友の発言を作る外部AI | `integrations/deepseek` |
| 定型応答 | AIの応答が検証を通らなかったときに、代わりに返す決まった応答 | `fallback` |
| 検証可能性 | 問題をサーバーが正しく採点できるかどうか | `VERIFIED`・`PROVISIONAL`・`UNSUPPORTED` |
